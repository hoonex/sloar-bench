    03 / Local-first

    Your repository is the workspace, not a cloud copy.

    Relay operates against local Git repositories. Repository state stays on your machine unless you explicitly connect a remote service.

    • ✓ Local branches and working-tree state stay local by default.
    • ✓ Remote services are explicit connections, not a hidden prerequisite.
    • ✓ Proposed changes remain separate until you choose what to apply.
