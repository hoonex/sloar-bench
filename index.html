01 / The idea

One task. More than one answer.

AI is useful at generating changes.
Judgment is still the scarce resource.

A single autonomous agent turns one model's assumptions into repository state. Relay inserts a review layer before that happens.

You see competing approaches while they are still proposals—then choose a whole solution, mix individual changes, or apply nothing.

03 / Review surface

Understand the tradeoff, not just the patch.

Reasoning summaries beside the actual diff.

Relay keeps every proposal legible at two levels: the agent's approach and the concrete repository changes. Compare intent, scope, touched files, and implementation before accepting anything.

    Side-by-side proposalsSame task, different implementation strategies.
  • 02
    Change-level decisionsAccept or reject files and hunks independently.

    Repository-aware contextEvery run starts from the same local Git snapshot.

04 / Local-first

Your repository starts—and stays—on your machine.

Local is the default state,
not a privacy mode.

Relay works directly with local Git repositories. Repository state remains local unless you explicitly connect a remote service. You choose the agent connections and the boundaries they receive.
